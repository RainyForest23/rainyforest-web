Same share, different energy.

Two workloads, each given the same slice of a server: 2 cores, 4 GB, 1 GPU.Run alone, one draws 145 W and the other 14 W.Billing by allocation charges them the same.

But they share one machine.

Put both on the same server and the meter reads one number.235 W at the wall: both workloads, plus the machine itself.Who used what?

CPU: by use.

The chip reports its own energy.Take off what it burns idle, then split the rest by how busy each workload kept it.

GPU: reserved, plus used.

A GPU held for you costs energy even while it waits, so that part follows the reservation.The rest follows use.

Memory: by what you hold.

Memory draws the same whether or not it is read.So it is charged by the amount held, not by activity.

One rule per part, one number per workload.

The three parts add up to each workload's energy.Checked against each workload measured alone, the split is within 0.4 % for the AI workloads and 4.1 % for Node.js.What is left over is the machine's own baseline.
